# PassionTech ERP bootstrap

Install `passiontech_erp` on a fresh Odoo 19 Community database with demo data
disabled. Odoo will install the complete approved Phase-1 PassionTech, Community,
and vendored OCA dependency stack.

This bootstrap intentionally excludes future or optional scope such as Fleet,
M-PESA, advanced Projects, commissions, territories, and broader HR functionality.
Company legal identifiers, statutory tax configuration, real users, opening stock,
opening balances, bank accounts, SMTP credentials, and production secrets remain
database configuration controlled by authorized business owners.
